Latest Blank Space version notes.

Blank Space v116 Latest full update

What changed

  • Achievements: rebuilt the website and Supabase achievement path again, repaired score-based Slope awarding, Google Snake original-mode protection, and A Small World Cup duplicate-goal protection.
  • Daily rewards: added a new 🎁 tab with a 7-day consecutive reward streak: 1, 2, 3, 4, 5, 8, then 10 points.
  • Owner Panel: combined Moderation and User Commands into Other Commands, added website bans and optional device bans, and removed the A Small World Cup reset command.
  • Timed Message: Send to everyone now excludes the sender, so the Owner does not receive their own global timed message.
  • Games: moved broken verified wrappers out of Verified Games, refreshed sources, added Level 67, Hole.io, and Stunt Bike Extreme, and added multi-source choices for the new Popular Games.
  • Settings: added 10 more local options, including compact cards, larger text, high contrast, rounded corners, hide thumbnails, auto-open last tab, quiet notifications, compact chat, safer external prompts, and smaller game controls.
  • Achievement search: added a search box so you can find achievements without scrolling.
  • Owner chat view: searching a username now opens a full read-only Chat-style view with a left conversation list, message bubbles, and an X close button. The Owner cannot type or send from it.
  • Daily rewards: the refresh and claim buttons now force-check the current Supabase session before saying you are signed out.
  • Achievement search: added a Search button, Enter-key search, Clear button wiring, and a visible result count.
  • Navigation: made the top tab bar a bit bigger than v104 while keeping it compact enough for school Chromebooks while keeping the gift tab and all existing tabs.
  • Tab Cloak: fixed custom tab icons so website URLs, favicon links, and direct image/icon URLs work correctly.
  • Safety: added a Settings toggle for the accidental close/refresh warning. It is on by default and can be turned off per browser.
  • Owner Panel: added a tool to rename the Block Protection setting label for everyone.
  • Chat safety warning: the warning now appears under the Chat title for 10 seconds with no close button whenever the Chat tab loads after a refresh or new tab.
  • True Member: Owner Panel can mark users as True Members with a green verified check next to their rank.
  • Buy: renamed Icons to Buy and added Icons/Banners sub-tabs with banner packs for leaderboard card backgrounds.
  • Online status: leaderboard and Friends now show Online/Offline pills based on recent activity.
  • Friend Requests: Settings now lets users turn friend requests on/off, and Friends → Look Up adds Block controls.
  • Chat: friend list height is capped beside the chat panel and group chats can open in a separate panel under single chats.
  • Games: refreshed requested Popular Games sources, added 17-0, favorites, current-player icons, and source dropdown defaults.
  • Account: added password change below username change for password-enabled accounts.
  • Achievements: rebuilt the v115 catalog/functions again and made Slope score goals easier.
Run supabase_v115_update.sql first, then upload this v115 website code to GitHub and hard-refresh the site.
